# codsoft_tasks
This repository contains the projects completed during my Java Development Internship at @CodSoft.

## 📁 Repository Structure
Each task is organized into its respective directory containing the source code and necessary documentation.

* **Task 3: ATM Interface** - A console-based banking application simulating real-world operations (withdraw, deposit, balance check).
* **Task 4: Quiz Application with Timer** - An interactive MCQ application featuring dynamic time limits and real-time score calculation.
* **Task 5: Student Course Registration System** - A backend system to manage student databases, course capacities, and registration/drop workflows.

## 🛠️ Tech Stack
* **Language:** Java (JDK 8 or higher)
* **Concepts:** Object-Oriented Programming (OOPs), Multi-threading (for Timer), Collections Framework, Input Validation.

## 🚀 How to Run the Projects
1. Clone this repository:
   ```bash
   git clone https://github.com
   ```
2. Navigate to the task directory you want to run.
3. Compile and execute the main Java class file.
